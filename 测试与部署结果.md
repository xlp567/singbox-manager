See the [public summary](reports/PUBLIC_VALIDATION.md) for historical results. Infrastructure identifiers, login information, raw service logs and private backup locations remain outside the published source.

Menu actions 15 / 16 / 17 share the transactional service entry point. Stop takes a snapshot, checks for inactive state and zero main PID, and restores the previous state on failure or interruption. Invalid configuration or a missing runtime cannot prevent stopping. Start and restart retain compatibility, configuration and running-health checks.

All 208 local regression tests, Bash syntax, ShellCheck and distribution checksums passed. This revision is tested locally with isolated service doubles. No VPS was contacted, so these results do not establish live deployment or end-to-end connectivity.
